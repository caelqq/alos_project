# Alos Project

## Summary
A Flutter Web starter project with a Home screen and a Login placeholder screen.

## Current stack
- Implemented now: Flutter Web / Dart
- Planned (not yet implemented): REST API, PostgreSQL

## Run locally
```
git clone https://github.com/caelqq/alos_project.git
cd alos_project
flutter pub get
flutter run -d chrome
```
